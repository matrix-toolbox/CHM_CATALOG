# Moved

The **Catalog of Complex Hadamard Matrices** has permanently moved to

### https://matrix-toolbox.github.io/chm

Everything that used to live here — including `CHM/`, `CHM_BC/`, `CHM_2U36/`,
`CHM_SH/`, `CHM_kU/` and `CHM_SINKHORN/` — is now kept in a single repository:

### https://github.com/matrix-toolbox/chm

Links of the form

    https://github.com/matrix-toolbox/CHM_CATALOG/blob/master/<dir>/<file>

are replaced by

    https://github.com/matrix-toolbox/chm/blob/main/<dir>/<file>

This repository is no longer updated. Its earlier contents remain available in
the git history.
